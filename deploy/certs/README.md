# Дополнительные корневые сертификаты для сборки образа

Если сеть, в которой собирается образ, проходит через корпоративный прокси с инспекцией TLS, положите сюда
корневой сертификат прокси в формате PEM с расширением `.crt` (например, `corp-proxy.crt`) и пересоберите образ:
`docker compose build`. Сертификаты добавляются в доверенные при сборке и в работающем приложении (загрузка
изображений по ссылке, OIDC). Файлы `*.crt` в git не коммитятся (`.gitignore`).
