# Правила оформления документов

## Структура статьи

1. Название — что делает читатель («Приёмка товара от поставщика», а не «Приёмка»)
2. Короткое описание: зачем документ и для кого
3. Пошаговая инструкция
4. Ответственные и сроки

## Пример блока кода

```bash
# выгрузка остатков из учётной системы
curl -H "Authorization: Bearer $TOKEN" https://erp.example.local/api/stock?date=today
```

## Формулы

Оборачиваемость запаса: $T = \frac{\bar{Z}}{S} \times 365$, где $\bar{Z}$ — средний запас, $S$ — выручка за год.

## Чего избегать

- Скриншоты вместо текста — текст на картинках плохо ищется (хотя OCR распознаёт русский и английский)
- Дублирование: лучше сослаться на страницу через `[[`
- Устаревшие документы: укажите **дату пересмотра** в свойствах страницы
