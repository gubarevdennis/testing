# UX-приёмка

Документ разделяет то, что проверено автоматически, и то, что требует людей: пилот с сотрудниками, другие браузеры, реальные устройства. Статус каждого UX-требования ведётся в `REQUIREMENTS_TRACEABILITY.md` (модули UI, LAYOUT, A11Y, EDITOR, TREE…); здесь — порядок приёмки и чек-листы.

## 1. Проверено автоматически (Chromium, каждый прогон CI)

| Свойство | Как проверяется |
|---|---|
| Отсутствие горизонтальной прокрутки и доступность ключевых элементов на 320/375/768/1024/1440/1920 px, светлая и тёмная темы | `tests/e2e/visual.spec.ts` (12 комбинаций × 5 экранов) |
| Реальный масштаб 200 % (1280×800 при 2×) | `tests/e2e/a11y.spec.ts` |
| WCAG 2.1 AA: нет серьёзных/критичных нарушений axe на входе, главной, странице, поиске, шаблонах, корзине, настройках, администрировании, импорте | `tests/e2e/a11y.spec.ts` |
| Клавиатура: Ctrl/⌘+K, справка «?», Esc закрывает и возвращает фокус, стрелки в дереве | `tests/e2e/a11y.spec.ts` |
| Уменьшение движения (`prefers-reduced-motion`) | `tests/e2e/a11y.spec.ts` |

| Задержка ввода | `tests/e2e/collab.spec.ts` (p95 ≈ 31 мс на 400 абзацах; полная методика ТЗ — в работе) |

## 2. Сценарий пилотного теста с сотрудниками (обязателен до приёмки, ТЗ v1.4 §6)

Участники: 5–8 новых сотрудников из разных отделов (склад, продажи, бухгалтерия, ИТ), без обучения. Наблюдатель не подсказывает. Фиксировать: успех/неуспех, время, ошибки, обращение к справке, субъективную нагрузку (NASA-TLX или SEQ 1–7).

| № | Задача | Порог |
|---|---|---|
| 1 | Создать вложенную статью в пространстве отдела | ≤ 1 мин |
| 2 | Оформить заголовки, список, выделенный блок (callout) | ≤ 2 мин |
| 3 | Вставить скриншот из буфера, подписать, открыть на весь экран и увеличить | ≤ 1 мин |
| 4 | Вставить таблицу из Excel, добавить столбец | ≤ 2 мин |
| 5 | Добавить ссылку на другую страницу через `[[` | ≤ 1 мин |
| 6 | Открыть доступ коллеге на редактирование | ≤ 1 мин |
| 7 | Найти документ по слову с опечаткой и неверной раскладкой | ≤ 1 мин |
| 8 | Восстановить предыдущую версию страницы | ≤ 2 мин |
| 9 | Импортировать DOCX и экспортировать страницу в PDF | ≤ 3 мин |
| Сквозной | Задачи 1, 2, 5, 6 подряд | ≤ 5 мин без подсказок |

Критерий приёмки: ≥ 80 % участников выполняют каждую задачу без помощи; ни одного P0-блокера (потеря данных, утечка прав, тупик, невозможность закрыть меню, перекрытие контента).

## 4. Принятые визуальные решения

* Дизайн-токены ТЗ сохранены (`#F8F9FB` фон, `#FFFFFF` поверхность, `#24272D` текст, `#68717D` вторичный текст, `#E5E8ED` границы, `#5A85C6` акцент). Для доступности основная кнопка использует более тёмный вариант акцента `#3F6AAB` (контраст белого текста 5,4:1 вместо 3,75:1), а границы полей ввода — `#858E9B` (3,3:1, WCAG 1.4.11); см. `DECISIONS.md`.
* Тёмная тема переопределяет те же токены; сохранённые в документах цвета текста и выделения автоматически сопоставляются тёмной палитре.
