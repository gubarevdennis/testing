# OWASP ASVS 4.0.3, уровень 2 — соответствие (R-SECURITY-004)

Самооценка по главам ASVS L2 на 23.10.2026: что реализовано, чем это подтверждено, и где честные пробелы. Это **не** независимый аудит и не пентест. Обозначения: ✅ — выполнено и есть автоматическая проверка; ◐ — выполнено частично или проверено только чтением кода; ✗ — не выполнено; н/п — неприменимо.

Автоматические проверки, на которые ссылается таблица:

| Проверка | Команда | Отчёт |
|---|---|---|
| SAST (eslint-plugin-security, eslint-plugin-no-unsanitized, eval-правила; 200 файлов кода, который поставляется) | `npm run security:sast` (входит и в `npm run lint`) | `test-results/security/sast-report.json` |

| DAST baseline (14 проб, ~750 проверок, все 195 операций из OpenAPI) | `npm run security:dast` (отдельный процесс, порт 4390, своя БД); то же в `tests/integration/security-dast.test.ts` | `test-results/security/dast-report.json` |

## Сводка пробелов L2

1. Пароль ≥ 12 символов и проверка по базе утёкших паролей (2.1.1, 2.1.7).
2. Тайм-аут бездействия сеанса (3.3.2).
3. Шифрование на уровне приложения для секрета TOTP (6.4) — остальное шифрование при хранении возложено на инфраструктуру.
4. TLS-конфигурация не проверяется автоматически (9.1); OIDC и ClamAV не проверены с реальными сервисами.
5. Dev-зависимости: 2 critical в vitest 3 (принято со сроком).
6. Независимый пентест не проводился; DAST — собственный baseline, не OWASP ZAP.
