# OWASP ASVS 4.0.3, уровень 2 — соответствие (R-SECURITY-004)

## Сводка пробелов L2

1. Проверка по полной базе утёкших паролей (2.1.7) — сейчас только офлайн-словарь распространённых.
2. Абсолютный срок сеанса 14 дней вместо 12 ч (3.3.2) — компромисс, настраивается `SESSION_TTL_HOURS`; тайм-аут бездействия 12 ч есть.
3. Шифрование при хранении (кроме секрета TOTP) возложено на инфраструктуру (6.4).
4. TLS-конфигурация не проверяется автоматически (9.1). OIDC и ClamAV проверены с реальными сервисами в тестовом окружении (oidc-provider, clamd), но не с корпоративным IdP заказчика.
5. Dev-зависимости: 2 moderate в `@vitest/mocker` (браузерный режим не используется; принято со сроком до перехода на vitest 4.1.12).
6. Независимый пентест не проводился; DAST — собственный baseline, не OWASP ZAP.
